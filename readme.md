# QuantByProf v4.0

A single-file study tool for CAT/GMAT quantitative concepts, quick revision, and short practice games.

## What's included

- **Revise:** 52 built-in concept cards across 6 topics and 26 chapters, with Foundation and Advanced levels.
- **Afterimage:** Memorise a formula during a brief preview, then identify it from multiple choices.
- **Faultline:** 52 curated, source-linked challenges. Diagnose a faulty mathematical step and choose the correction; missed concepts are added to the Revise Queue.
- **Personalisation:** Add custom concept cards, save cards, mark concepts mastered, and manage the Revise Queue.
- **Backup and sync:** Export/copy saved state as JSON and restore it later.
- **Math notation:** Supports common `_` subscript and `^` superscript notation in concept content.

## Run it

1. Download `QuantByProf_v4.html`.
2. Open it in a modern browser (Chrome or Edge recommended).
3. Choose **Revise** to study cards or **Minigames** to launch Afterimage or Faultline.

The file stores progress in the browser's local storage. Progress is local to that browser/profile; use **Sync** to back it up before clearing browser data or moving to another device. Also this file can be accessed online via the links from the pages part of this site.

**Internet note:** Tailwind CSS and Google Fonts are loaded from external CDNs for styling. The HTML can open without them, but its appearance may be reduced when offline.
